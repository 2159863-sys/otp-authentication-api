# OTP Authentication API

A REST API for OTP-based authentication built with Node.js, Express.js and MySQL.

## Features

- Generate a 6-digit OTP
- Store OTPs with an expiration time
- Verify OTPs
- MySQL database integration
- REST API endpoints

## Requirements

Before running the project, make sure you have:

- Node.js
- MySQL
- npm

## Installation

Clone the repository:

```bash
git clone https://github.com/2159863-sys/otp-authentication-api.git
cd otp-authentication-api
npm install
```
